# ai-agent-rag
## Description
This is a project for the Q&A with RAG. It supports the user to upload PDFs, TXT, Markdown, and Docs files.

## Technical Stack

### Frontend
- React
- React hooks
- React Router
- Tailwind CSS
- Shadcn/ui
- React hook form
- Zod
- Zustand
- React Query
- Tanstack Table React
- vitejs
- Better Auth

### Backend
- Python
- FastAPI
- Better Auth
- Pydantic
- SQLAlchemy
- Alembic
- PostgreSQL

### AI Agent
- LangGraph
- mem0
- Qdrant
- Local LLM with Openai API standard
